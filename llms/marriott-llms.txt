# Marriott International

> Marriott International is the world's largest hotel group by room count, headquartered in Bethesda, Maryland, operating and franchising roughly thirty brands from The Ritz-Carlton, St. Regis and W through Marriott Hotels, Sheraton, Westin and Courtyard down to Fairfield, Moxy and StudioRes, plus the Homes & Villas by Marriott Bonvoy home-rental marketplace and the Marriott Bonvoy loyalty program. Its API posture is closed: there is no public developer program, no self-serve signup, no published rates/availability/booking API, no SDK, no sandbox, no changelog and no status page. This file is generated by API Evangelist from the artifacts in the api-evangelist/marriott repository. Marriott does not publish an llms.txt of its own — https://www.marriott.com/llms.txt returns HTTP 404.

## Access reality

- Marriott operates a Broadcom Layer7 developer portal at https://devportalprod.marriott.com — it returns HTTP 200 but its anonymous API catalogue (`/api/apis`) returns zero items and its home content returns HTTP 401. Signing up grants access to nothing that is published.
- Programmatic access to Marriott rate, availability and content data is contractually prohibited by default. Marriott's Terms of Use forbid "robots, spiders, or other automatic or high-volume methods or devices ... without our written permission".
- Marriott's real programmatic distribution runs through the three global distribution systems (Amadeus, Sabre, Travelport), through OTAs and bedbanks, and — for Homes & Villas short-term-rental supply — through a Channel Connectivity Program that PMS and channel-manager vendors join via a Salesforce partner contact form.
- There is no bulk export, reporting or data-portability API operation in any published Marriott artifact. The only exit path Marriott publishes is the individual consumer privacy right.

## APIs

The six documents below are Marriott OpenAPI specifications left publicly readable on SwaggerHub under the "marriott-api" owner. They describe Marriott's internal and partner-facing estate. They are not an offer to third-party developers, and none of them is callable without a Marriott partner relationship.

- [Marriott TIP Internet Portal API](https://api.swaggerhub.com/apis/marriott-api/tip-internet-portal-api-spec/1.0.2): Partner-facing in-hotel internet integration — generate a guest landing-page URL, validate a guest by room number and last name against the cloud PMS, post an internet purchase back to the PMS. Basic auth mints a Bearer JWT at /v3/ent-auth/sso/token.
- [Marriott Loyalty Account Merge API](https://api.swaggerhub.com/apis/marriott-api/account-merge/1.0.2): Merges or transfers one Bonvoy member profile into another, keyed on member account type code and unique identifier.
- [Marriott Data Collection API](https://api.swaggerhub.com/apis/marriott-api/Data_Collection_API/1.0.0): Captures and publishes stay-event data for a reservation confirmation number, feeding a downstream consumer called PACD; associated with digital-key and door-lock events.
- [Marriott Commerce Payment Processor API](https://api.swaggerhub.com/apis/marriott-api/commerce-payment-processor/1.0.0): Submits a payment to a payment processor over an XML FreedomPay Freeway service operation. The only Marriott document that names the Marriott API Team (apidevteam@marriott.com).
- [Marriott Finance Status Notifier API](https://api.swaggerhub.com/apis/marriott-api/finance-all-statusnotifier/1.0.2): Receives processing status for files generated by Marriott's finance adapters; OAuth2 client-credentials.
- [Marriott Hotel Operations ARA Preview Submit API](https://api.swaggerhub.com/apis/marriott-api/hotel-operations-ara-preview-submit-api/1.0.0): Submits a preview request for ARA automated room assignment. Declares no servers at all.
